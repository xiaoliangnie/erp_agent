## 1. 通用数据模式

### 1.1 主数据源：`div#_jt_data`（推荐）

老版 jTable（`.aspx`）列表/明细页会在 HTML 中内嵌：

```html
<div id="_jt_data" style="display:none;">
  {"dp":{"PageSize":500,"DataCount":N,...},"datas":[{字段...}, ...]}
</div>
```

| 字段 | 含义 |
|------|------|
| `datas` | 行数据数组（**后台字段名**） |
| `dp` | 分页：`PageSize` / `PageIndex` / `DataCount` / `PageCount` 等 |

**采集步骤：**

1. 使用已登录浏览器会话（带 Cookie）  
2. `GET` 对应 `.aspx` 页面  
3. 截取 `id="_jt_data"` 节点文本并 `JSON.parse`  
4. 使用 `datas` 作为结果集  

```javascript
function parseJtData(html) {
  const i1 = html.indexOf('id="_jt_data"');
  if (i1 < 0) throw new Error('no _jt_data');
  const i2 = html.indexOf('>', i1);
  const i3 = html.indexOf('</div>', i2);
  return JSON.parse(html.slice(i2 + 1, i3));
}
// const { datas, dp } = parseJtData(html);
```

**注意：**

- 必须登录态；裸 `curl` 通常无效  
- 明细页常需业务主键（如 `po_id`）  
- **不要依赖页面 DOM 虚拟滚动**，易截断/串单  

### 1.2 列表刷新：`am___=LoadDataToJSON`

```http
POST /app/.../xxx.aspx?ts___={时间戳}&am___=LoadDataToJSON
Content-Type: application/x-www-form-urlencoded; charset=UTF-8
```

Body 一般为筛选表单字段 + `owner_co_id` / `authorize_co_id`。  

实际返回**经常是整页 HTML**（内嵌 `#_jt_data`），不一定是纯 JSON；解析方式同 1.1。

### 1.3 其它动作：`am___={MethodName}`

```http
POST /app/.../xxx.aspx?ts___={ms}&am___={MethodName}
```

用于汇总计数、补齐字段、配置查询等，不一定返回表格主数据。
